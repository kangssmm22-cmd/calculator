왼쪽 월배당 후보 종목을 드래그해서 오른쪽 3개 선택칸 중 하나에 놓으면 종목명, 종목코드, 1주당 월 배당금, 상승률이 자동 입력됩니다. 드롭 직후 현재가 API 조회가 자동 실행됩니다. API가 실패하면 현재가를 직접 입력해도 계산됩니다.
